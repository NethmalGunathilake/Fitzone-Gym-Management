# FitZone – Gym Management Web Application

## About
A full-featured gym management web application developed as part 
of the Web Application Development (WAD) module at ICBT Campus 
(Cardiff Metropolitan University).

## Features
- User Registration & Login System
- Member Dashboard
- Admin Dashboard
- Staff Dashboard
- Class Scheduling & Management
- Nutrition Tracking
- Member Management
- Database Integration

## Tech Stack
- PHP
- MySQL
- HTML & CSS
- JavaScript
- XAMPP (Local Server Environment)

## How to Run Locally
1. Install XAMPP on your computer
2. Clone or download this repository
3. Copy the project folder to `C:/xampp/htdocs/fitzone`
4. Open XAMPP Control Panel
5. Start Apache and MySQL
6. Go to `http://localhost/phpmyadmin`
7. Create a new database
8. Import the `users.sql` file
9. Open browser and visit `http://localhost/fitzone`
